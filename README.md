# SQL Practice Repository – Data Analyst Preparation

## 📌 Overview

This repository is a **comprehensive SQL practice collection** designed for **Data Analyst aspirants and freshers**. It covers SQL concepts from **basic fundamentals to advanced window functions**, with a strong focus on **interview readiness and real-world use cases**.

All queries are written with **clear structure, meaningful examples, and clean naming conventions**, making this repository suitable for:

- Data Analyst / Business Analyst interview preparation
- Strengthening SQL fundamentals
- Showcasing practical SQL skills on GitHub

---

## 🛠️ Topics Covered

- SQL Basics (DDL & DML)
- Filtering & Sorting
- Joins
- Aggregations
- Subqueries
- Window Functions
- Real-world employee and order-based examples
