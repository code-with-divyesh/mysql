# 📚 Library System Management – SQL Project

## 📌 Project Overview

This project is a relational database system designed to manage the operations of a library.  
It simulates real-world library workflows such as book issuance, return tracking, overdue detection, revenue calculation, and branch performance reporting.

The project demonstrates strong SQL fundamentals along with intermediate-level data analysis techniques, making it suitable for Data Analyst preparation.

---

## 🎯 Project Objectives

- Design a normalized relational database schema
- Implement CRUD operations
- Perform analytical queries using SQL
- Generate summary reports using CTAS (Create Table As Select)
- Apply real-world business logic such as overdue tracking and revenue reporting
- Strengthen SQL skills for Data Analyst roles

---

## 🗂 Database Schema

The database consists of the following tables:

### 1️⃣ branch

Stores information about different library branches.

### 2️⃣ employee

Stores employee details and associates them with branches.

### 3️⃣ members

Stores member registration information.

### 4️⃣ books

Stores book details including rental price and availability status.

### 5️⃣ issued_status

Tracks book issuance transactions.

### 6️⃣ return_status

Tracks book return transactions.

---

## 🔗 Entity Relationships

- Each employee belongs to one branch.
- Each issued book is linked to:
  - A member
  - A book
  - An employee who processed the issue
- Each return is linked to a previously issued book.

This structure ensures proper relational integrity using primary and foreign keys.

## 📊 Business Logic Implemented

### 🔹 Overdue Detection

Identifies members who have not returned books within 30 days.

### 🔹 Revenue Calculation

Calculates total rental revenue generated by each branch.

### 🔹 Book Availability Management

Updates book status when returned.

### 🔹 Performance Reporting

Generates branch-level performance reports including:

- Number of books issued
- Number of books returned
- Total revenue generated

### 🔹 Employee Ranking

Identifies top 3 employees who processed the most book issues.
